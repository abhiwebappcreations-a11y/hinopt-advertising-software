# Deployment & Infrastructure Documentation

This directory contains deployment runbooks, Docker configurations, infrastructure provisioning, and environment setups.

## Infrastructure Components
- **Supabase Cloud Projects:** Provisioning guide for `hinopt-core` and `admobitics-ads`.
- **Cloudflare R2:** Bucket configurations, CORS rules, lifecycle retention rules (Campaign End + 3 Days).
- **Backend Services:** Containerization and deployment guides for Node.js/TypeScript microservices.
- **Android Display Fleet:** Device Owner provisioning scripts (`dpm set-device-owner`) and over-the-air (OTA) APK deployment runbooks.
