# Product Requirements Documents (PRDs)

This directory contains formal Product Requirements Documents defining the capabilities of HINOPT Advertising Software.

## Index of PRDs (Gate 1 Deliverables)
- `PRD-001-core-domain-and-signage-terminology.md`: Domain models, terminology, and system invariants.
- `PRD-002-direct-booked-campaign-and-day-parting.md`: Campaign scheduling, date/time boundaries, playlist logic.
- `PRD-003-hinopt-master-licensing-and-device-authority.md`: Cryptographic licensing, activation flows, device life cycles.
- `PRD-004-offline-resilience-and-time-security.md`: 4-state time machine, rollback quarantine, sync behaviors.
