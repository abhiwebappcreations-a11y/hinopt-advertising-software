# Deployment & Orchestration

This directory contains containerization files (Dockerfiles, Docker Compose), orchestration manifests, and environment variable templates.

## Structure
- `docker/`: Dockerfiles for backend microservices (`licensing-service`, `advertising-service`, `media-service`).
- `docker-compose.yml`: Local multi-service development environment.
- `env.example`: Template for environment variables (strictly excluding real secrets).
