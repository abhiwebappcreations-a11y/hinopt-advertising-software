# Supabase Database Migrations & Schemas

This directory contains database migration scripts, seed data, and Row-Level Security (RLS) policies for the two isolated Supabase projects.

## Project Segregation
- `hinopt-core/`: Migrations for HINOPT licensing, device registry, and audit logs.
- `admobitics-ads/`: Migrations for Admobitics campaigns, schedules, playlists, and proof-of-play reports.
