# Product Documentation

This directory contains high-level product documentation, business requirements, user personas, and user journey workflows.

## Subsections
- **Personas:**
  - HINOPT Platform Super-Administrator (manages device authorizations, plans, licensing).
  - Admobitics Campaign Operator (manages advertisers, campaigns, playlists, media).
  - Venue Operator / Field Technician (installs TPC 151TCT displays, pairs devices via activation codes).
- **Workflows:**
  - Device Provisioning & Licensing Lifecycle.
  - Campaign Creation & Day-Parting Scheduling.
  - Playback Reporting & Advertiser Verification.
